# bigO

A focused digital studio building modern websites, web apps, and digital solutions that are fast, secure, and built to last.

## Stack
- Next.js 16 (App Router)
- React 19
- Tailwind CSS v4
- Framer Motion

## Getting Started

1. Clone the repository
2. Run `npm install`
3. Set up environment variables:
   Create a `.env.local` file and add your Web3Forms access key:
   ```
   NEXT_PUBLIC_WEB3FORMS_ACCESS_KEY=your_access_key
   ```
4. Run `npm run dev` to start the development server at `http://localhost:3000`.
